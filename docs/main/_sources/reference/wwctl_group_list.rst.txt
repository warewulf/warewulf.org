wwctl group list
----------------

List node groups and their members

Synopsis
~~~~~~~~


Show groups and their members.
Membership is the union of the per-node `groups:` field and any
`groups:` declared on a profile the node inherits. Without the
GROUP argument, all groups are shown (including the built-in
`all` group).

::

  wwctl group list [GROUP ...]

Options
~~~~~~~

::

  -h, --help       help for list
  -n, --noheader   Print a comma-separated list of member nodes with no header or table formatting (deduped across all requested groups). Requires at least one GROUP.
